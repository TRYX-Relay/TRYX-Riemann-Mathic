# Companion instruments

- [Zeta sniffer](zeta-sniffer/index.html): numerical critical-line candidate search, supported heights 0–100. Keep engine.js alongside index.html. Small residuals and cutoff agreement are numerical observations, not certified zero counts.
- [RE6B beta](re6b/index.html): complete retrieved beta V3 notebook and embedded reference instrument. [Version and source notes](re6b/README.md) distinguish it from the archived V15 HTML source.

Download and extract the publication ZIP, then open either local HTML entry point in a browser. GitHub displays source rather than executing these HTML files. Both runnable folders contain their required local script files. Read each tool’s scope and version notes before interpreting its output.
